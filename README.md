# StealthNote

Welcome to the **Anonymous Message Sender** project! This is a simple web application that allows users to send anonymous messages. The messages are sent to predefined Discord webhooks. The app also features a sleek video background, a dark mode toggle, and a responsive design.

## Features

- **Anonymous Messaging**: Send messages anonymously without revealing your identity.
- **Video Background**: A visually appealing video background that enhances the user experience.
- **Dark Mode**: Toggle between light and dark modes for better readability in different lighting conditions.
- **Responsive Design**: The app is fully responsive and works seamlessly on desktop, tablet, and mobile devices.
- **Discord Integration**: Messages are sent to Discord via webhooks for easy monitoring.

## How It Works

1. **User Interface**: The user types a message in the text area and clicks the \"Send\" button.
2. **Data Collection**: The app collects the user's IP address and device information using browser APIs.
3. **Discord Webhook**: The message, along with the collected data, is sent to predefined Discord webhooks.
4. **Dark Mode**: Users can toggle between light and dark modes for a personalized experience.

## Technologies Used

- **HTML5**: For structuring the web page.
- **CSS3**: For styling the application, including animations and responsive design.
- **JavaScript**: For handling user interactions, dark mode toggling, and sending data to Discord webhooks.
- **Discord Webhooks**: For receiving and logging messages in a Discord channel.

## Installation

To run this project locally, follow these steps:

1. **Clone the Repository**:
   ```bash
   git clone [https://github.com/your-username/anonymous-message-sender.git](https://github.com/ItzMeHyper/StealthNote-AnonymousMessage_Web.git)
   cd StealthNote-AnonymousMessage_Web
2. **Open the Project**:
   - Open the `index.html` file in your browser.

3. **Customize Discord Webhooks**:
   - Replace the Discord webhook URLs in the `script.js` file with your own webhook URLs.

4. **Add Video Background**:
   - Replace the `assets/Impostor.mp4` file with your own video file or update the path in the HTML.

## Usage

1. Open the application in your browser.
2. Type your message in the text area.
3. Click the \"Send\" button to send the message anonymously.
4. Toggle dark mode using the \"🌙 Toggle Dark Mode\" button.
